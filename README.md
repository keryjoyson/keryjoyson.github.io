# Kery Joyson | Resume Website

A simple, responsive one-page resume site for **Kery Joyson**, Salesforce Developer & Analyst based in Hyderabad, India.

**Live site:** https://keryjoyson.github.io

## About

This is a static website built with plain HTML and CSS, with no frameworks and no build step. It is hosted for free on GitHub Pages and covers:

- Professional summary
- Work experience (Salesforce Associate, Analyst)
- Skills (Apex, LWC, SOQL, Java, Python, JavaScript, HTML, CSS)
- Salesforce certifications (Platform Developer I, Administrator, Associate)
- Education and interests
- A downloadable PDF resume

The page works on phones and desktops, and switches to dark mode automatically when the visitor's device uses it.

## Project structure

```
.
├── index.html     # Page content
├── style.css      # Styling (light/dark themes, responsive layout)
├── README.md      # This file
└── Kery_joyson_resume.pdf   # Downloadable resume
```

## Run it locally

No setup needed. Download or clone the repo and open `index.html` in any browser.

```bash
git clone https://github.com/keryjoyson/keryjoyson.github.io.git
cd keryjoyson.github.io
```

## Deployment

The site is published with GitHub Pages from the `main` branch (root folder). Because the repo is named `keryjoyson.github.io`, it is served at `https://keryjoyson.github.io`.
